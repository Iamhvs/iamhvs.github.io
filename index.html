🛠️ Troubleshooting Tips

The download will not start

Some browsers block downloads until you explicitly allow them. Check the download tray or the address bar for a permission prompt and allow the file. If the page itself does not load, try again in a different browser or on a different network.

The assistant closes immediately after opening

This is often caused by security software scanning a newly downloaded program. Wait a moment and try opening it again. If it still closes, run it from a folder you own, such as your Desktop, rather than from a temporary location.

A prerequisite check keeps failing

Read the description attached to the failing item carefully. Most failures point to a very specific cause — a missing folder, a file in an unexpected location, or a permissions issue. Fix that one item and rerun the check before changing anything else.

LumaCore dependencies are not detected

Confirm that the components exist where SteaMidra expects them to be. If you recently moved folders or restored files from a backup, paths may have changed. Reset the location and run the dependency check again.

Steam-related settings still need attention

Make sure Steam is fully closed while you apply configuration changes. Some settings are only read at startup, so a running Steam client can hide the change until you restart it.

Everything passes but the configuration does not seem to apply

Restart both applications in order: close SteaMidra first, then the assistant, then reopen the assistant and let it verify once more. A clean restart resolves the majority of "applied but not visible" situations.
